# expenseMonitor

R Shiny application for uploading, validating and analysing expense data from receipts.

## Features

- Upload expense data from Excel files
- Data validation and error handling
- Interactive expense visualisations
- Expense summaries and analytics
- Modular Shiny architecture

## Technologies

- R Shiny
- tidyverse
- Plotly
- bslib
- testthat

## Getting started

1. Clone the repository
2. Open the project in RStudio
3. Run `app.R`
4. Upload the sample file located in `data/receipts_test.xlsx`
